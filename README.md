# Letterology

Official instrument. Letterize a username. Read today's luck. Time a decision.

A letter does not change its nature — only its willingness. That is luck.

## Use it

1. Enter the handle you actually use.
2. Read the Path (role / how / where) against today's court.
3. Take the three moves: **do this / wait on / ask**.
4. Letterize an act (`quit`, `ask them`, `ship the launch`) to see if the day will have it.

Doctrine, Method, Atlas, and Key are in the app.

## Doctrine, short

- We letterize **usernames**, not birth names.
- First letter sits the house. Weight sits manner and field.
- Digits are the Count (1 is A, 0 is the Fool).
- Sisaveli's tiers are offices *inside a name*, not a caste of the alphabet.
- Favorable currents = today's date-house plus its allies. Contrary currents = its enemies.
- Solar / Lunar is a tilt, not a gender of the soul.
